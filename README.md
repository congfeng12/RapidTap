# RapidTap 连点器（macOS）

一个原生 macOS 连点工具：按下一个**你自定义的触发键**，就以**可调频率**连续模拟鼠标左键点击。
内置拟人化节奏（随机间隔、随机按压时长、偶发停顿、坐标微抖动），让点击节奏不呈现明显的程序固定周期特征。

- 原生实现：Swift + AppKit，编译产物是一个 `.app`，不依赖 JVM / Python / Electron
- 已在本机验证：macOS 27.2（Darwin 27.2.0）+ Apple Silicon（arm64）
- 目标最低系统：macOS 13.0

## 快速开始

```bash
git clone https://github.com/congfeng12/RapidTap.git
cd RapidTap
./build.sh      # 编译并打包成 RapidTap.app
./run.sh        # 启动
```

首次启动需要在 **系统设置 → 隐私与安全性 → 辅助功能** 中勾选 `RapidTap`（否则只能看到界面、无法拦截按键和模拟点击），授权后界面顶部会变绿。

接着点右上角「设置」，在设置面板里点「重新设置」录一个触发键（支持 `F6`–`F12` 以及 ⌘⌥⌃⇧ 等修饰键），选好模式后关闭面板，再打开主界面顶部的「连点器」开关，按触发键即可开始连点。完整说明见下文。

## 功能

| 能力 | 说明 |
|------|------|
| 连点器开关 | 主界面顶部开关，**默认关闭**；关闭时触发键完全不被拦截，不会长期占用你设置的按键 |
| 全局触发键 | 任意按键，**包括 ⌘ / ⌥ / ⌃ / ⇧ / Caps Lock / Fn**；设置面板里「重新设置」后按下即可设置（默认 `F6`） |
| 触发键拦截 | 命中触发键时事件被吞掉，不会传给前台应用/游戏 |
| 两种模式 | **按住连点**：按住触发键才连点；**按一下切换**：按一下开始、再按一下停止 |
| 连点频率 | 1 ~ 60 次/秒，实时显示对应间隔毫秒数 |
| 拟人化随机 | 间隔抖动（0 ~ 45%）+ 按压时长随机 + 约 1.4% 概率插入长停顿 + 启动随机延迟 |
| 坐标微抖动 | 可选，每次点击落点偏移 ±1.2 像素 |
| 事件源 | 使用 `hidSystemState`（HID 事件源），兼容性优于普通合成事件 |
| 外观主题 | 浅色 / 深色 / 跟随系统，切换立即生效并持久化 |
| 开机自启动 | 「通用」分组里的开关，走系统登录项（`SMAppService`），可在系统设置中撤销 |
| 自动更新 | 启动时静默检查 GitHub Releases，发现新版本可一键下载安装并自动重启；也可随时手动检查 |
| 配置持久化 | 触发键、频率、模式、拟人化、坐标抖动、主题等**每次改动立即原子写入**配置文件，强杀进程也不丢 |

## 界面

按 macOS「系统设置」的分组表单规范设计（效果见上方截图），主界面只保留最常用的内容：

**主界面**
- 顶部控制卡：连点器开关 + 实时状态（已关闭为红色电源图标 / 已开启为绿色 / 连点中），副标题显示触发键与已点击次数；
- 连点设置：点击频率、拟人化随机节奏、间隔随机幅度、点击坐标微抖动；
- 只有在**未授权**或**发现新版本**时，才会多出一条提示横幅。

**设置面板**（右上角「设置」，以 sheet 打开）
- 辅助功能权限状态与授权引导；
- 触发按键（含 ⌘⌥⌃⇧ / Caps Lock / Fn）与触发模式；
- 主题（浅色 / 深色 / 跟随系统）、开机自启动、软件更新；
- 风险提示。

细节：
- 灰底（`underPageBackgroundColor`）+ 白色圆角卡片，自动适配深色模式与系统强调色；
- 每行配 SF Symbols 图标，开关项使用系统 Switch，主操作是强调色按钮；
- 顶部透明标题栏，窗口可整体拖动；
- 所有控件都带无障碍标签，装饰性图标不参与朗读。

## 首次使用必须授权（否则无法点击）

macOS 不允许普通进程模拟其它应用的输入，必须授予「辅助功能」权限：

1. 启动 `RapidTap.app`，界面顶部会显示红色的「辅助功能权限：未授权」；点右侧「去授权」按钮（若系统弹出了授权提示，直接点「打开系统设置」）；
2. 系统设置 → **隐私与安全性 → 辅助功能** → 勾选 `RapidTap`（列表里没有就点 `+` 添加 `RapidTap.app`）；
3. 如果按键拦截仍不生效，再到 **隐私与安全性 → 输入监控** 中允许 `RapidTap`；
4. 回到应用，状态变绿即可使用。**无需重启应用**，程序每 0.2 秒自检一次权限。

### 授权会不会丢？

- **关闭再打开应用：不会丢。** 系统授权跟着这份应用走，不需要重复授权。
- **重新编译：不会丢。** 项目已配置本地稳定签名身份（见下节）。
- 应用会记住「曾经授权过」。万一授权以后真的失效，界面会显示「授权已失效」并提示如何恢复，而不是只显示未授权。

### 本地稳定签名身份（为什么重新编译也不用重新授权）

ad-hoc 签名（`codesign --sign -`）的「指定要求」是 cdhash，每次编译都会变，macOS 会把它当成新程序，之前的授权随之失效——这正是「重开就失效」的根因。

`./setup-signing.sh` 会在本机创建一个自签名证书 `RapidTap Local Signer`，放在专用钥匙串 `~/Library/Keychains/rapidtap-signing.keychain-db`。用它签名后，指定要求固定为 `identifier + 证书指纹`，重新编译保持不变，系统授权可以一直沿用。

- 首次使用执行一次：`./setup-signing.sh`（`build.sh` 会自动检测并使用）
- 没有创建也能用，`build.sh` 回退到 ad-hoc，但重新编译后需要重新授权
- 删除该证书：`security delete-keychain ~/Library/Keychains/rapidtap-signing.keychain-db`

> 该证书仅用于给本机这个应用签名，不参与系统信任设置，也不会用于其它软件。

## 使用说明

1. 点「重新设置」，按下想用的触发键（`Esc` 取消）。普通按键（如 `F6`–`F12`）触发时会被拦截；⌘⌥⌃⇧ 等修饰键**不会被拦截**，仍可正常参与组合快捷键，建议配合「按住连点」使用。
2. 选择触发模式：
   - 按住连点：适合"按需点"；
   - 按一下切换：适合长时间挂机，再按一下停止。
3. 拖动「点击频率」滑块设置速度，右侧会实时显示间隔（例如 12 次/秒 ≈ 间隔 83 ms）。
4. 需要更强拟人化时保持「拟人化随机节奏」勾选，并调整「间隔随机幅度」（默认 ±22%）。
5. 点「开始连点」或直接按触发键，状态栏实时显示已点击次数。

点击位置固定为**当前鼠标所在位置**，不会锁定坐标，也不会移动光标（除非手动开了坐标微抖动）。

> 关闭窗口即退出程序，连点会立即停止；程序不在后台常驻。

### 更新

应用基于本仓库的 GitHub Releases 做更新：

- **启动时自动检查**：打开应用 1.5 秒后静默检查一次，有新版本时「通用 → 软件更新」会显示「发现新版本 vX.Y.Z」，按钮变为「更新到 vX.Y.Z」；
- **手动检查**：随时点该行的「检查更新」按钮；
- **一键更新**：点「更新」后自动下载 → 解压 → 校验签名与版本号 → 替换应用 → 重启，全程无需手动操作；
- 若更新失败（例如应用放在只读位置，或网络不可用），可以到 [Releases](https://github.com/congfeng12/RapidTap/releases) 手动下载安装包。

### 开机自启动

在「通用 → 开机自启动」打开开关即可，本质是调用 `SMAppService` 注册登录项，可在**系统设置 → 通用 → 登录项**里查看和撤销。

- 开关状态直接读取系统登录项，不是应用自己记的，所以不会出现"开关开着其实没注册"的情况；
- 若系统要求确认，开关会保持关闭并在副标题提示去「登录项」里允许；
- **移动或改名 `RapidTap.app` 后需要重新打开一次开关**，因为登录项记录的是应用路径。

### 设置存在哪里

所有设置（触发键、触发模式、点击频率、拟人化开关与幅度、坐标抖动）都会**在改动的瞬间**写入：

```
~/Library/Application Support/RapidTap/config.json
```

- 采用原子写入（先写临时文件再替换），拖动滑杆连续修改、强制关进程都不会丢；
- 启动时读该文件，缺失字段会回退默认值，不会把整份设置重置；
- 恢复默认设置：`rm ~/Library/Application\ Support/RapidTap/config.json`，下次启动自动生成默认配置；
- 旧版本存在 UserDefaults 的配置会在首次启动时自动迁移过来，无需手动处理。

## 关于"避开脚本检测"的能力边界（请务必阅读）

程序做了什么：

- 点击间隔在设定值附近随机浮动，不是固定周期；
- 每次按下的持续时长随机（默认 16 ~ 52 ms，并受频率上限约束）；
- 约 1.4% 的概率插入一次 55 ~ 160 ms 的停顿，模拟人手换气/走神；
- 开启后每次落点有 ±1.2 像素偏移；
- 启动时随机延迟 8 ~ 50 ms，不会每次都在按键的同一时刻开始；
- 事件通过 `hidSystemState` 事件源投递到 HID 层，而不是 `combinedSessionState` 之类的合成源。

这些手段能消除"完全固定的机器周期"这一最明显的特征，但**不能保证**绕过专业反作弊系统（如 Easy Anti-Cheat、BattlEye、Vanguard、nProtect 等）：它们会从驱动层、内存、行为模型、输入设备指纹等多个维度判定，用户态模拟输入天然无法对抗。**在联网游戏中使用第三方连点工具很可能违反服务条款并导致封号，风险自负。** 建议用于单机、办公自动化、重复性操作等场景。

## 常见问题

**按触发键没反应**
- 看界面左上角权限是否绿色；红色说明没授权。
- 触发键可能被其它全局热键软件占用（如截图工具、输入法）。
- 如果用的是 ad-hoc 签名（没执行过 `setup-signing.sh`），重新编译后需要去「辅助功能」里重新勾选一次。

**能启动但点击无效**
- 没授权只能"看到界面"，无法注入事件。
- 前台应用开启了"安全输入"（密码框等）时，系统会忽略合成事件，这是 macOS 的保护机制。
- 部分全屏独占游戏会屏蔽合成鼠标事件，可先试窗口化/无边框。

**实际频率比设定值低**
- 拟人化随机本身会让平均值略低（偶发停顿），属正常现象；关掉拟人化即为固定周期。

**触发键选了 Tab/空格后，其它应用不能用了**
- 触发键是全局拦截的，换成 `F6`–`F12` 这类不常用键即可。

**想恢复默认设置**
```bash
rm ~/Library/Application\ Support/RapidTap/config.json
```
